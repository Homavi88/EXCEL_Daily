# Добавление месячных таблиц в мастер (VBA)

Готовый модуль: [`excel-append-to-master.bas`](./excel-append-to-master.bas)

## Установка

1. Откройте **месячный** файл как `.xlsm` (книга с макросами).
2. `Alt+F11` → в дереве проекта выберите эту книгу → **Insert → Module**.
3. Вставьте содержимое файла `excel-append-to-master.bas` (можно без строки `Attribute VB_Name`, если Excel сам задаёт имя модуля). Если модуль уже был вставлен ранее — замените его целиком свежей версией (исправлен compile error на `Dim eNum`).
4. В начале модуля найдите константу и укажите путь к мастеру:

```vb
Private Const MASTER_PATH As String = "C:\Data\Lab_Master.xlsx"
```

5. Сохраните книгу как **Excel Macro-Enabled Workbook (*.xlsm)**.
6. При запросе включите макросы (Enable Content / Включить содержимое).

## Запуск

- **Диалог макросов:** `Alt+F8` → выберите `AppendTablesToMaster` → Run.
- **Кнопка:** на любом листе вставьте кнопку (Developer → Insert → Button) и назначьте макрос `AppendTablesToMaster`.

Макрос всегда работает с **активной** книгой как источником. Имя месячного файла не важно — каждый месяц можно открывать новый `.xlsm` с этим же модулем.

## Что делает макрос

Листы/таблицы (имя таблицы = имя листа):

| Лист        | Ключ дедупликации   |
|-------------|---------------------|
| Stem_Flakes | Batch               |
| DIET        | Batch               |
| CF          | Batch               |
| Kitchen     | Batch               |
| Ripper I    | Batch               |
| Other TI    | Date + Cell + Point |

- Если файла мастера по `MASTER_PATH` ещё нет — создаётся новый `.xlsx` с теми же листами, заголовками и ListObject-таблицами.
- В мастер добавляются только **новые** строки; дубликаты по ключу пропускаются.
- После работы мастер сохраняется; на экране — отчёт: сколько строк добавлено / пропущено по каждому листу.

Мастер — обычный `.xlsx` (макросы в нём не нужны).

## Power BI

Подключайте Power BI к файлу мастера (`MASTER_PATH`), а не к месячным книгам. После каждого запуска макроса обновляйте запросы / семантическую модель в Power BI.

## Важно

- В источнике на каждом листе должна быть таблица Excel (ListObject) с **тем же именем**, что и лист.
- Должны существовать ключевые столбцы (`Batch` или `Date` / `Cell` / `Point` для Other TI).
- Набор и порядок столбцов в месячном файле и в мастере должны совпадать.
- Папка из `MASTER_PATH` уже должна существовать; при ошибке структуры мастер не портится (изменения не сохраняются).
- При сбое MsgBox показывает текст причины, номер Err (если был runtime) и имя процедуры/листа. Пустое «Ошибка 0» больше не должно появляться: проверка структуры и отсутствующая папка мастера идут как понятные сообщения, а не через пустой `Err`.
